<h1 align="center">Extensions needed</h1>

- Anypoint Extension Pack
- Anypoint Code Builder

## Init script 

1. Cmd + Shift + P
2. ```bash
    Java: Clean Java Language Server Workspace
    ```
3. click on "Restart"


## Create new project

1. Cmd + Shift + P
2. ```bash 
    DataWeave: Create New Library Project
    ```
3. click on "Yes"
